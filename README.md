# Muhammad Naeem — Portfolio

Personal portfolio of **Muhammad Naeem**, Flutter & Software Developer.
Live: https://mnaeem700.github.io

Built with React, Vite, Three.js (React Three Fiber), GSAP and Lenis. Dark and light themes included.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in /dist
```

## Edit content

All text, projects, experience and skills are in [`src/data.js`](src/data.js).
App screenshots and icons are in `public/apps/`, and the profile photo is `public/naeem.jpg`.

## Deploy

Every push to `main` builds and deploys the site to GitHub Pages through `.github/workflows/deploy.yml`.
In the repo settings, set **Settings → Pages → Source** to **GitHub Actions**.
